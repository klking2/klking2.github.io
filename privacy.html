私隱政策 Privacy policy

適用於 Edward AIOS Drive Sync 的 Google Drive 連接。更新日期：2026-10-14。

This policy covers the app’s Google Drive connection. Updated: 2026-10-14.

存取及使用 Access and use

工具只使用 drive.file 存取由它建立或使用者明確提供的特定 Drive 檔案，並核對檔案名稱、大小、雜湊、父資料夾及擁有人等相關 metadata。資料只用於擁有人指定的私人工作交接、接收及完整性確認。

The app uses only drive.file to access specific files it creates or that the user explicitly makes available. Relevant metadata such as name, size, hashes, parent folder and owner is checked to verify private delivery and reception.

儲存 Storage

已保存的工作進度、背景／技能版本、已確認材料及原生收據會放入擁有人指定的私人 Drive 交接區及接收機本機。相容階段可另外使用擁有人指定的私人 GitHub 工作庫。資料庫、Google／Codex 憑證、依賴及原生聊天 session 各機獨立保存，不加入交接包。OAuth 憑證只保存在本機受限制的私人檔案。

Selected saved progress, background and skill versions, confirmed materials and native receipts are stored in the owner’s designated private Drive handoff folder and receiving computers. A designated private GitHub workflow repository may also be used during compatibility operation. Databases, Google/Codex credentials, dependencies and native chat sessions stay device-local and are excluded from transfer packages. OAuth credentials are stored in restricted private local files.

分享及用途限制 Sharing and limited use

不公開、出售或用於廣告。交接只送往擁有人指定的私人服務及其電腦。使用 Codex 處理材料須另行沿用使用者指定的工作與工具授權，並受該服務條款約束；Drive 連接不會自行發送其他檔案給 AI 服務。

Data is not published, sold or used for advertising. Transfers go only to the owner’s designated private services and computers. Processing materials with Codex requires the user’s separate task and tool authorization and is subject to that service’s terms; the Drive connection does not independently send other files to AI services.

本工具從 Google API 取得的資訊，其使用與轉移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

保留、刪除及撤銷 Retention, deletion and revocation

交接檔案保留在使用者管理的私人資料夾，直到使用者自行刪除；刪除雲端檔案不會自動刪除各機原資料。使用者可在 Google 帳戶的第三方連接中撤銷授權，也可移除本機連接憑證。停止授權不會自動清除已交付資料。需要協助可聯絡下列地址。

Handoff files remain in the user-managed private folder until the user deletes them. Cloud deletion does not automatically delete original local data. Authorization can be revoked in the Google Account’s third-party connections, and local connection credentials can be removed. Revocation does not automatically erase previously delivered data.

登入及安全 Sign-in and security

登入由 Google OAuth 完成；工具不讀取瀏覽器或 Google Drive App 的登入 token。交付完成須原始檔案回讀匹配；另一機接收另行核對。

Sign-in uses Google OAuth. The app does not read browser or Google Drive desktop app tokens. Delivery is confirmed through matching raw-file readback; reception on another device is checked separately.
